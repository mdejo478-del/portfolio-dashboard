# IPMS — מערכת לניהול תיק השקעות

> השקעה לפי הקצאה, לא לפי רגש.

דשבורד Next.js לניהול תיק השקעות אישי: מעקב אחרי אחזקות, יומן מסחר, התראות סטיה מהקצאת יעד, וגרף עקומת שווי — עם חשבונות משתמשים נפרדים ואימות בדוא"ל.

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר יעלה בכתובת [http://localhost:3000](http://localhost:3000).

## משתני סביבה

| משתנה | תיאור |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | טוקן של בוט טלגרם לשליחת התראות הרשמה (אופציונלי) |
| `TELEGRAM_CHAT_ID` | מזהה הצ'אט שאליו נשלחות ההתראות (אופציונלי) |

ללא שני המשתנים האלה, שליחת ההתראות לטלגרם פשוט לא מתבצעת (no-op).
